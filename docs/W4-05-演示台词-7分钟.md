# W4-05 · 七分钟演示台词

> 台账验收口径：完整走一遍不超过 7 分钟，中途不需切窗口、不需看笔记。
> 每句标注【界面 + 操作】。★ 段落即「故意失败 → 调度接管 → 当场救回」。
> 彩排要点：双屏布局——左边数据大屏（1920），右边编排屏；演示前先登录（密码见 data/password.json）。
> 兜底：第 6 节回放不依赖网络；另备 90 秒录屏（本文件同目录下的彩排录屏）。

---

## 0:00–0:40 开场 · 数字先钉死

【大屏首页 · 不操作，让 KPI 自己说话】
"各位评委好。这是销售数据分析大屏：总销售额 1684 万 8875，总利润 412 万，利润率 24.5%，300 笔订单——这些数字来自 data.csv，逐位一致，我待会儿会用 AI 问答当场对账。"

【大屏首页 · 按 F5 连刷三次】
"刷新三次，数字一个都不会变——大屏和 AI 共用 data_source.py 这一个数据入口，没有第二个真源。"

## 0:40–1:40 AI 问答 · 同一次提问两条屏都看得见

【大屏左上角 · 点「✨ AI 分析」】
"我问它：广东省的销售额是多少？"

【AI 面板 · 等回答出现】
"回答 123 万 5074，附了口径说明。注意右边——"

【切右屏 · 编排屏 /orchestration】
"这次提问在编排屏上是实时可见的：节点正在按 pending → running → pass 变色，延迟在一秒以内。左边提问、右边看它是怎么跑的，两件事发生在同一次 run 上。"

## 1:40–2:40 编排屏 · 三角色与一条流水线

【编排屏中部 DAG 图区】
"流程不是一行函数调用，是一张可配置的图：Analyst 只管取数，Critic 独立调用只挑错不改数，Curator 写结论。角色卡在 config/roles.json 里，改禁止事项、重启即生效，代码零改动。"

【编排屏左侧队列区 + 右侧通道区】
"任务队列带优先级和 deadline，超时节点判 timeout、立刻让出槽位；模型通道那边，主模型连续失败会自动切备用，切换事件写进 trace 的 fallback 字段——降级必须留痕，不许悄悄换。"

## 2:40–4:20 ★ 故意失败 → 诊断 → 当场救回

【AI 面板 · 输入「广东省的毛利率是多少？」】
"现在故意问一个口径陷阱题：毛利率。数据里没有成本字段，模型的常规习惯是拿利润率冒充毛利率。"

【编排屏 · 指 Critic 节点变 fail、诊断事件出现】
"看右边：Critic 挑错，verdict=fail 落进 trace。诊断模块不是问模型'你错哪了'——模型自归因不可靠——而是用确定性规则归类：取数错、口径错、表达错、无数据。这道题被归成口径错。"

【编排屏 · 指第二轮节点】
"按类给不同的修正策略：取数错就重取，口径错就退回上一步核口径，表达错只改表达、一个数字都不许动。第二轮 prompt 和第一轮有实质差异，重试上限 2 次，超限才转人工兜底。"

【AI 面板 · 指最终回答】
"最终它诚实地拒答并说明原因，而不是编一个数。trace 里能看到 fail → diagnosis → retry → pass 的完整链条。"

## 4:20–5:20 节点详情 · 当面读出数字

【编排屏 · 点开任一节点的详情抽屉】
"点任何节点，抽屉里有这次调用的输入、输出、耗时、token、重试原因。比如这里：Analyst 第 1 次调用，耗时 1.4 秒，token 进 512 出 128——评委问'第 3 步为什么这么走'，答案就在这个抽屉里，不用形容词。"

【编排屏右侧 run 列表 · 点选历史 run】
"每次 run 都落盘成 runs/{run_id}.jsonl，历史随时可查。"

## 5:20–6:20 断网兜底 · 回放

【编排屏 · 选中一条历史 run，点「回放这一遍」】
"答辩现场网络不可控，所以有回放：选中历史 run，时间轴可拖、可暂停，整条事件流本地重演——这一节完全不需要模型在线。我预跑了 3 条 trace，包括一条失败 run，断网也能完整演示。"

## 6:20–7:00 一键回归 · 收尾

【终端 · 跑 python -m evals.run】（演示前预跑，现场只展示报告）
"最后是验证闭环：11 题固定用例集，其中 3 道故意设计的易错题，判定方式分精确值、必须包含、必须拒答三种。一条命令出报告：通过率、平均耗时、平均 token、失败清单。恢复后首次回归 11/11 通过率 100%，报告 JSON 存档在 evals/reports/。失败题还会自动回流进 regression 分组，下次必测。"

【双屏收尾 · 面向评委】
"总结一句话：这不是一个会聊天的报表，是一个可观测、可回放、可验证的多智能体编排平台——每一步都有 trace，每个数字都有出处。"
